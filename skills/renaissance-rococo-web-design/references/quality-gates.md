# Quality Gates

Report only checks that were actually performed. A valid skill file does not prove browser compatibility; a static preview does not prove motion.

## Research

- Historical, technical, and case-study claims link to sources.
- Observation, interpretation, and project decision are distinct.
- References are inspected as actual images or pages before visual claims are made.
- Transferable mechanisms are separated from source-specific text, identity, objects, and composition.
- Unknown licenses stay unknown; public availability is not treated as reuse permission.

## Visual design

| Area | Passing evidence | Failure signal |
|---|---|---|
| desktop scale | real 1440×900 and 1920×1080 viewport previews | portrait poster or browser frame used as the final desktop design |
| material | visible differences among paint, cut/torn paper, print, metal, and web text | blur, aging, generic gold, or noise standing in for material |
| composition | named focal event, subordinate zones, and eye path | equal size, brightness, and density; mirrored decorations |
| continuity | entrance, collection, detail, article middle, artwork view, and return share specific anchors | inner pages revert to a component-library default |
| expression and reading | prose is quiet and stable while expression survives in header, margin, crop, or passage | only the cover is designed, or scenery sits under every line |
| truth | real content or clearly marked placeholders; originals remain authoritative | invented biography, claims, or redrawn work presented as original |

Do not use abstract beauty scores. Attach each issue to a state and location, then propose an observable correction.

## Web path

1. Enter from the home page, open a collection item, and return to the original browsing position.
2. Open article and artwork URLs directly, including a heading or footnote hash.
3. Read mid-article, select and copy text, use browser find, follow a footnote, and return.
4. Stress long CJK titles, mixed scripts, long links, captions, formulas, tables, and empty collections.
5. Test landscape and portrait artwork without distortion.
6. Verify facts and destinations on About/social links.

## Input and fallback

- Keyboard traversal, visible focus, semantic links/buttons, and Escape behavior work.
- Reduced motion preserves all states with substantially less spatial movement.
- Fast scroll, reversal, repeated clicks, forward/back, and interrupted animation do not trap or hide content.
- Image, mask, or enhancement-script failure leaves navigation and content usable.
- Zoom, fallback fonts, narrow windows, and varied artwork ratios do not create unintended page-level horizontal scroll.

## Record format

For each check record: target / page state / environment / action / observed result / pass or fail / evidence / correction or reason untested.
